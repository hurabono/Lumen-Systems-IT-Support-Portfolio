# Lumen Systems — IT Support Portfolio

> ⚠️ **Disclaimer:** Lumen Systems is a fictional company created for portfolio purposes only. All employees, tickets, and scenarios in this repository are simulated to demonstrate real-world IT support workflows, troubleshooting methodology, and documentation practices. No real company data is used.

## Purpose

This repository simulates the day-to-day IT Support operations of a mid-sized Toronto-based company. It is designed to demonstrate practical, job-ready IT support skills — including ticket triage, troubleshooting methodology, technical documentation, and knowledge base management — using realistic scenarios based on common issues faced by IT Support teams in Canadian workplaces.

## How to Navigate This Repo

1. **[company-profile.md](./company-profile.md)** — background on Lumen Systems and its IT environment (systems, tools, team size)
2. **[org-chart.md](./org-chart.md)** — IT department structure and roles
3. **[templates/ticket-template.md](./templates/ticket-template.md)** — the format every ticket follows
4. **tickets/** — real-world style tickets, each showing the full troubleshooting process from intake to resolution
5. **knowledge-base/** — internal documentation written after recurring issues, demonstrating knowledge-sharing skills

## Skills Demonstrated

- Ticket triage & prioritization (P1–P4)
- Structured troubleshooting methodology
- Active Directory / Microsoft 365 account administration
- Basic networking troubleshooting (DNS, DHCP, VPN)
- Technical writing & knowledge base documentation
- ITIL-aligned incident/problem/change terminology
